# Heidi Gathers

This is the new hack club haven tutorial followed, then remixed into a hella goofy speedrun game where Heidi collects Fear emojis for Tsoding himself. I know, very creative. The task is timed, so I can challange you to beat my best of 12.55!

## Play

Control with WASD or the Arrow Keys, you can only pick up one emoji at a time, and you need to get over the image of Tsoding to deposit it.
